# Village Society System

## Goal
Villages become persistent social units rather than collections of unrelated villagers.

## Phase 6 foundation
- A village has a stable persistent identity.
- Population is derived from live villagers and persisted village state.
- Important village events become shared historical facts.
- Resource pressure can influence village state without inventing resources.

## Source of truth
Minecraft world state remains authoritative. The village system records derived social history and decisions, not fabricated facts.
