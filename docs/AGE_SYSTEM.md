# Age System

## Goal

Every villager has a stable, persistent age. The age is generated once and never rerolled when the player asks about it.

## Rules

- Child villagers: 4–13 years.
- Adult villagers: 18–60 years.
- Baby/adult status is authoritative from Minecraft; the mod assigns an age within the corresponding narrative range.
- Age is NPC state, not dialogue text.
- Asking the same NPC about age must always return the same age.
- Age is stored with the NPC identity so it survives reloads.
- Future systems may advance age using world time.

## Future

Age will become an input to:

- Family relationships.
- Birth and childhood events.
- Adulthood.
- Marriage and descendants.
- Generational memories.
- NPC personality and activity.
- Chronicle entries.

The dialogue/conversation system must read the stored age rather than inventing a new number.
