# Home System

Homes persist by villager UUID and represent real locations in the Minecraft world.

## Assignment
A home prefers an actual nearby bed and a usable entrance/door when available. A fallback position may exist only until real world evidence is found.

## Ownership and access
Access is derived from relationship, personality and invitation. The system must never claim an NPC witnessed an intrusion unless the NPC was actually present/able to observe it.

## Intrusion
An intrusion is detected when a player crosses the owner's home boundary. Unauthorized entry can increase stress, create memory and alter the relationship, subject to cooldown.

## Storage
Personal storage references real Minecraft containers. Simulation inventory state must be reconciled with actual item stacks; items cannot appear from dialogue or bookkeeping alone.
