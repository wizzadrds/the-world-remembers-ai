# Phase 9 Acceptance

Phase 9 is complete only when:
- [x] Timeline UI opens in-game.
- [ ] Timeline contains grounded historical events.
- [ ] People view exposes remembered people tied to the player's world history.
- [ ] Relationships view exposes persisted relationship state.
- [ ] Families view exposes persisted family links.
- [ ] Village history view exposes persisted village history/events.
- [ ] Chronicle data survives reload because it is rebuilt from persistent state.
- [ ] GameTests/unit tests validate deterministic aggregation and empty-world behavior.
- [ ] Final CI validates Gradle build/tests, client compilation and headless server smoke test.
