# Phase 7 Acceptance

Phase 7 is complete only when all are green in CI:

- [ ] Real nearby NPCs become direct witnesses to observed events.
- [ ] Direct knowledge persists and is deduplicated.
- [ ] NPC-to-NPC reports transfer only existing knowledge.
- [ ] Rumor confidence degrades with propagation/time.
- [ ] Direct knowledge outranks reported and rumored knowledge.
- [ ] Persistent conversation records are bounded and deduplicated.
- [ ] Grounded dialogue never references unavailable facts.
- [ ] Dedicated Minecraft GameTests cover witness, propagation, degradation and persistence.
- [ ] Population-scale conversation processing passes performance validation.
- [ ] Final Gradle build/tests and headless Fabric server smoke test pass.
