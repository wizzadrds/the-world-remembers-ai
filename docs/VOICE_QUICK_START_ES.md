# Inicio rápido de voz — The World Remembers

## Solo necesitas una clave de API

La instalación normal no requiere Python, terminal, entornos virtuales, Piper ni modelos RVC.

1. Instala el mod y abre Minecraft.
2. Abre **The World Remembers → Voice Settings**.
3. En **AI & Speech**, elige **Gemini** o **OpenAI**.
4. Pega una clave de API del proveedor elegido.
5. Pulsa **Recommended defaults** y guarda.
6. En **Audio**, selecciona el micrófono y los auriculares y guarda.
7. Acércate a un aldeano y mantén pulsada **V** para hablar.

La clave se guarda en la configuración local de Minecraft. No la publiques ni la compartas en capturas o registros. El uso de las API puede tener coste y está sujeto a los límites de tu proveedor.

## ¿Y VillagerTITAN?

VillagerTITAN/RVC queda como una opción avanzada de voz local. Requiere sus propios archivos de modelo y dependencias, por lo que no se activa como requisito de la instalación normal. Si el campo **Villager TTS command** está vacío, el mod utiliza la síntesis en la nube del proveedor seleccionado.

Si algo falla, revisa el mensaje de error de voz en el registro de Minecraft. Los errores de inicio de sesión de Realms/TLauncher no forman parte del sistema de voz.
