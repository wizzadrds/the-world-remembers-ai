# Phase 10 Acceptance

Phase 10 is complete only when:
- dream generation is deterministic and persistent across the same sleep epoch;
- dream content is grounded in actual NPC memories/fears/relationships;
- memory, fear, nostalgia and impossible dream types are represented;
- dreams cannot mutate factual world state by generation alone;
- dedicated GameTests validate generation and state isolation;
- performance remains bounded for population-scale dream evaluation;
- CI validates the full build and headless Fabric smoke test.
