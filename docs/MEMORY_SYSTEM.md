# Memory System

## Memory event shape

A memory contains, at minimum: event type, time, location, actor, target, witnesses, importance, emotional/social tags and consequences.

## Importance

TRIVIAL, INTERESTING, IMPORTANT, HISTORICAL, LEGENDARY.

Not every Minecraft action becomes a permanent memory.

## Lifecycle

Created -> reinforced -> recalled -> summarized -> degraded/forgotten -> possibly transmitted as rumor or inherited as family history.

## Grounding

Dialogue must only claim facts present in the known world state or in the NPC's knowledge set.
