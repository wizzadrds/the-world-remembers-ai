# THE WORLD REMEMBERS

> **Minecraft nunca olvida lo que haces.**

Minecraft Java Fabric mod focused on persistent memory, relationships, emergent NPC behavior, families, village society, rumors, local voice, chronicles and dreams.

## Status

**Current milestone:** v1.0.0 — The World Remembers

## Quality bar

The 1.0 milestone is release-ready only when the complete automated unit-test suite, Minecraft GameTests, headless Fabric server smoke test, persistence checks and final CI workflow all pass.

## Development principles

1. Simulation is the source of truth.
2. Generative systems must not invent world-state facts.
3. Important events are remembered; trivial actions are not stored forever.
4. Behavior is contextual.
5. Voice is local-first and optional.
6. Dreams are derived inner-life state and never authoritative world facts.
7. Systems remain modular.
